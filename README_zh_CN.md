# 表格转数据库

一键把思源笔记里的**表格块**转换为**属性视图（数据库）**，也支持从 **CSV / Markdown 表格**导入到新数据库或已有数据库。

---

## 功能

### 表格 → 数据库
- 一键把任意普通表格变成可筛选、可排序的数据库。
- **转换前预览面板**：展示列名和推断类型，可逐列覆盖类型、**选择主列**。
- **智能类型推断**：`文本`、`数字`、`复选框`、`单选`、`多选`、`网址`、`邮箱`、`电话`、`日期`。
- 可设置**数据库名称**。
- 实时**数据预览**（默认 10 行），支持「显示更多」/「全部显示」按钮。
- 多选列以 **chip 标签**方式渲染。

### 导入数据（CSV / Markdown 表格）
- **创建新数据库** — 从 CSV 或粘贴的 Markdown 表格导入。
- **导入已有数据库** — 自动列匹配 + 去重。
- 去重策略：**按主列去重**、**按整行去重**、不进行去重。
- **实时预览**：显示列映射、新增/重复行数、数据预览。
- 插入位置：**光标位置**或**文档末尾**。
- 列类型映射（沿用已有字段类型或重新指定）。
- 多值列归一化处理，兼容各种分隔符（逗号、分号、空格）。

### 通用
- 每次写入前自动**生成文档历史快照**，出错了可随时从思源「文件历史」回退。
- 完整**中英文案**（跟随思源界面语言自动切换）。
- 通过**顶栏按钮**（`⇧⌥T`）或**命令面板**触发。

---

## 使用方法

### 转换表格
1. 将光标放在表格内，或选中表格块。
2. 点击顶栏**「表格转数据库」**图标，或按 `Shift+Alt+T`。
3. 弹出转换预览面板 — 检查列类型、选主列、设置数据库名称。
4. 点击**确认转换**。

### 导入数据
1. 点击顶栏图标 → **导入数据**。
2. **步骤 1**：粘贴 CSV/Markdown，或上传 CSV 文件。
3. **步骤 2**：选择**创建新数据库**或**导入已有数据库**。
4. **步骤 3**：配置列类型映射、去重策略、插入位置。
5. 点击**导入**执行。

## 安装

### 从集市安装
1. 思源 → 设置 → 集市 → 插件。
2. 搜索**「表格转数据库」**→ 安装。
3. 启用插件。

### 手动安装（开发）
1. 从 [Releases](https://github.com/shuojie819/siyuan-table-to-database/releases) 下载最新 `package.zip`。
2. 思源 → 设置 → 集市 → 插件 → 从安装包导入。
3. 或解压到 `<工作空间>/data/plugins/siyuan-table-to-database/`。
